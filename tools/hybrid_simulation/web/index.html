這個模擬如何避免作弊？有什麼限制？

真實動作 → 渲染 RGB → 真實 MediaPipe Full → 骨架觀測；另一條路把固定安裝旋轉、方向雜訊與朝向漂移加到虛擬 IMU。估計器只收到這些觀測及共同的初始校正姿態，動態真值留在評分器。

相機場景固定放置 19 個裝置；只有你勾選的部位會提供 IMU 資料。方向雜訊為每軸高斯雜訊，漂移主要是共同朝向偏差、另加小幅個別差異；此處不是完整硬體或 AHRS 電路模擬。

「目前加權」直接使用專案現有旋轉融合器。「實驗回饋」額外用可信骨段的水平角差估計共同朝向偏差，並排除與慣性／時間預測嚴重不一致的影像方向。看不見人時停止新影像修正，IMU 繼續更新；這套新增保護目前只用於模擬比較。

姿態誤差是骨盆對齊後 24 關節平均距離；方向誤差是有穿戴感測器部位的全域旋轉誤差。沒有驗證真實全域位移。影像可能比乾淨的 IMU 更差，所有結果照實顯示。

v2 對肘、膝使用這個 rig 宣告的單軸彎曲限制（0–145°），以遠端 IMU 與影像共同解算整條手臂／腿，並停止用單一食指點猜測完整手腕方向。預設 IMU 對照也使用相同關節限制，舊版自由關節仍可切換檢查。

v3 在局部旋轉上加入因果式 1€ 自適應濾波：慢動作抑制雜訊，快動作降低延遲；純 IMU 與融合使用完全相同的參數。可取消「姿態降抖」比較 v2 原始解算。「3D 連續播放」只對已錄製的相鄰姿態做最短路徑旋轉插值，不增加觀測率，不改置信度或評分。即時系統若要使用同樣的相鄰幀插值，須額外緩衝一個輸入幀。

純 IMU 分支只使用已穿戴部位的旋轉；未觀測部位保留初始／前幀方向。它沒有額外的全身推論網路。共同朝向回饋需要骨盆或胸口參考，只有雙前臂時不啟用該回饋。真實姿態視圖中的遮擋物半透明，便於從側面檢查場景。

本實驗未啟動 GlobalPose 分支，也不能替代真人資料驗證。初始相機／穿戴方向已校正，骨架尺寸已知；未模擬所有自遮擋、磁場、延遲或安裝滑動。
