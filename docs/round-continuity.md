# 回合恢復

回合等待與回合結束分開處理。斷線、過期姿態、背景分頁、主動暫停、校正或 WebGL 恢復時，保留分數、血量與剩餘時間。所有等待原因都解除後，自動接回原回合。重疊的等待只計算一次。

重設航向、配戴或原點時，清除未完成動作與攻擊速度，下一筆新姿態重新建立基準，避免位置跳變造成假命中。已得分的內容保留。場景編輯與對手距離調整也不重開回合。

缺資料可以先開始等待，恢復後才消耗遊戲時間。站姿基準嘗試穩定一秒，最多等待 2.5 秒後以當前有效姿態開始。未校正是提示，不是開始門檻。離線時按身體校正會排隊，連上姿態服務後送出，也可以取消排隊。

相機標記遮擋只固定水平位置，肢體遊戲仍使用新鮮姿態。不能將相機遮擋期間的固定位置解讀為已量測到真人沒有移動。

正常到時、對戰勝負、使用者結束或更換遊戲仍可結束。中途切到準備或進階設定保留回合。資料來源改變會更新標示，整場成績保留較保守來源，含示範資料的回合不列為純即時成果。

## 驗證

執行 `python tests/test_webui_browser.py` 與 `python tests/test_webui_browser.py --suite webui_continuity.js`。後者包含超過回合長度的斷線、交錯暫停、校正排隊、動作重設與資料恢復，不把過期姿態當作有效動作。

這些是 Chromium/WebGL 的控制資料測試。實體 BLE 喚醒、穿戴誤判率及真人定位精度須另外量測。
