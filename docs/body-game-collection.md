# 統一遊戲集合

大廳主層：身體記憶序列、全身定格、Combat；原十三種姿態與反應練習收在可展開的姿態訓練內。搜尋會展開訓練分類，從紀錄選回動作也會展開。

記憶序列：觀看傾身／蹲低順序，依序重現，每個動作保持 350 ms，動作之間回到站姿。成功加十分並加長序列，最多六個。錯誤後重新觀看。

全身定格：綠燈 2.5 秒內交替抬腳，黃燈一秒準備，紅燈 1.8 秒保持身體相對形狀與離地高度。紅燈移動會失去該段未結算步數。容差目前是設計參數，尚非真人準確率驗證結果。骨盆水平絕對位移未列為判定依據，因此不宣稱能量測真實行走距離。

兩者使用共用站姿校正、60 秒回合、暫停、來源判定、結算、最佳成績及紀錄。完成段落與失誤次數保存在 bodyStats，JSON 備份驗證與還原保留這些欄位。中斷會清除未完成判定，重新預告，不把斷訊算成動作失誤。

合成姿態回放與鍵盤測試工具已從主要介面移除，保留開發函式供規則檢查，不寫入正式排行榜。

機器人對戰也在同一個遊戲頁選擇，難度、距離、開始與結算都共用頁面流程，沒有獨立的對戰分頁。舊 `#combat` 連結仍能選中對戰，`#games` 直接進入大廳。畫面名稱改為中文，動作訓練集中在可收合分類中。

驗證：`node tests/body_games_rules.cjs` 檢查順序成功、錯誤、紅燈肢體移動與過期資料恢復；`python tests/test_webui_browser.py` 檢查真實頁面、站姿校正、關節輸入得分、共用結算、紀錄備份及回放隔離。未完成六顆 IMU 真人穿戴驗證，不能宣稱已證明舒適度、準確率或可玩性。
