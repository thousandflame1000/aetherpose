1. 共用 3D 場景

新檔 webui/avatar.js；修改 webui/index.html、webui/combat.js

以前 Combat 是獨立的畫面，現在所有模式都在同一個場景裡，切換時人體和視角都不會跳掉。

  • 主控畫面、Combat、小遊戲共用一個 Three.js 場景、一個繪圖迴圈，場景裡只有一個人體。
  • 切換模式不重建場景，回到主控畫面時恢復原本的視角。
  • 人體網格和關節都以骨盆為原點，身體旋轉後網格與碰撞位置不會錯開。
  • 新增視角快捷鍵（Front／Side／Top／Reset）、跟隨人物、隱藏面板、全螢幕。
  • 新增畫質設定（Low／Balanced／High）和亮度調整，設定存在瀏覽器裡。
  • 場景上方顯示推論裝置、姿態更新率、推論與網格延遲。
  • Three.js 0.128.0 改放在專案內，不再依賴 CDN。

2. 13 款姿勢小遊戲（本週新增）

  • Reach Targets伸手碰觸目標
  • Squat Rhythm深蹲節奏
  • Balance Hold單腳平衡
  • Dodge Flow左右閃避
  • Sky Catch雙手接高空目標
  • Clap Pulse拍手節奏
  • March Step交替抬膝
  • Star Hold展臂保持
  • Cross Knee對側手碰膝
  • Guard Drill雙手防守
  • Shoulder Tap雙手碰肩
  • High Five交替擊掌
  • Bow Rhythm前傾節奏

所有遊戲共用的規則

  • 開局前要站直、雙腳平放並穩定 1 秒，才開始 60 秒倒數；畫面會顯示校正進度和沒通過的原因。
  • 可以暫停、中途結束、關閉音效。
  • 追蹤中斷、資料過期、切換資料來源或切到背景時，回合會自動結束。
  • 最佳成績依遊戲和資料來源（Demo／Mixed／Live）分開記錄，只有完整跑完的回合才算。
  • 回合紀錄保留最近 50 場，可以篩選、匯出 JSON。

判定看的是身體部位的相對位置。例如 Squat Rhythm 要頭降低至少 18 公分、骨盆降低至少 12 公分，並停留 0.5 秒；只低頭不算分。

3. Combat 改進

修改 webui/combat.js、webui/combat.css；新素材 webui/assets/robot/

  • 改在共用場景中進行，不再另外建立人體和畫面。
  • 對手換成 Quaternius 的 RobotExpressive 模型（CC0 授權），攻擊、受擊、倒地、勝負都有對應動畫。
  • 對手距離可以調整，範圍 0.8–1.8 公尺，預設 1.1 公尺。
  • 場景中設為實心的物件會擋住雙方的攻擊。

4. 場景物件與碰撞（本週新增）

新檔 webui/physics.js、webui/scene-assets.js、webui/scene-storage.js

  • 場景加入後牆和兩根柱子。人體與場景用包圍盒碰撞，並檢查兩幀之間的移動路徑，快速移動也不會穿牆，碰到牆會沿著牆面滑動。
  • 可以匯入 GLB 模型（單檔最多 20 MB，場景最多 8 個），或從內建場景庫加入（木燈籠、機器人）。
  • 可以拖曳移動、調整大小與角度、複製，每個物件可以復原或重做 50 步。
  • 每個物件可以分別設定要不要顯示、有沒有碰撞。
  • 場景可以存在瀏覽器裡，重新整理後還原。
  • Reach Targets 放目標時會避開場景物件。

5. 後端與推論橋接

Rust 後端

修改 src/app/ws_server.rs、src/app/types.rs、src/app/backend/commands.rs

  • 新連線會主動要一份最新狀態，所以追蹤器沒在送資料時，新開的頁面也能立刻拿到狀態。
  • 廣播跟不上時不再中斷轉送；連線一邊關閉時，另一邊也會一起關掉。

Python 推論橋接

修改 frontend/mesh_bridge.py、frontend/transpose_runner.py、frontend/ws_client.py

  • 只把新鮮的資料送進推論：快照超過 1 秒、單顆追蹤器超過 0.5 秒，或數值異常（NaN、零四元數）都會排除。
  • 只有使用示範資料時，資料循環才會重設原點；6 顆都是即時 IMU 時不會。
  • 網格頂點改以靜止時的骨盆為原點，與關節一致。
  • 模型載入完成後主動送出網格拓撲，比模型更早連上的頁面也拿得到。
  • 姿態封包加上版本號，重送同一份資料不會被當成新動作。
  • 跟不上的連線會被關閉，讓瀏覽器自動重連。
  • WebSocket 用戶端的佇列上限改為 16 筆，並記錄收到時間；修好正常關閉後無法重連的問題。

6. 啟動腳本

修改 run.ps1、setup.ps1、webui/run.ps1、webui/stop.ps1；新檔 webui/services.ps1

  • run.ps1 和上層的 start.ps1 預設改開網頁介面，不再開舊的桌面視窗。
  • 以前的 run.ps1 會先強制關掉所有 Python 程式。現在只啟動還沒在跑的服務，並用執行檔或腳本的完整路徑確認是本專案的程式；不是的話既不啟動也不關閉。
