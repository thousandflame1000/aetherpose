# 訓練回顧與 CSV 匯出

遊戲頁的「回合紀錄」可篩選遊戲、輸入來源、對戰難度，以及本週／上週。日期以台灣時間（UTC+8）的週一 00:00 為起點，不隨電腦時區改變。

摘要按示範、即時、混合來源分開列出場數、完成／中斷與累積回合時長。時長包含中斷回合實際記錄的秒數，不是有效運動時間。不同遊戲的分數不加總。

按「匯出目前篩選（CSV）」下載畫面篩選下的全部紀錄，即使列表只顯示最近 10 場。欄位包括台灣時間、遊戲、來源、分數、秒數、是否完成與原因。CSV 使用 UTF-8 BOM，可用試算表開啟。沒有資料時按鈕停用。原本的全部 JSON 匯出仍可使用。

資料仍只保存在目前瀏覽器，最多最近 50 場。週摘要不是完整歷史，示範與混合資料也不能證明真人訓練成效。清除紀錄後摘要與匯出同步更新。

2026-10-18 驗證：兩種尺寸各 774 項 Chromium/WebGL 檢查通過，11 項專案整合測試通過。新增涵蓋台灣週界線、前週上下界、分來源摘要、共用篩選、CSV 編碼與空資料。此次未重跑完整 Live 套件。

## JSON 備份還原

「匯出全部（JSON）」可下載目前最多 50 場紀錄。換瀏覽器後，在「還原回合備份」選擇該檔案。畫面先預覽新增、重複、合併後保留場數及會移出的現有場數；按「確認合併備份」才寫入。要先保存現有資料時，先匯出目前的 JSON。

還原只影響回合歷史，不改最佳成績、校正、硬體或設定。合併後依時間排序，仍只保留最近 50 場。重複回合保留本機版本。備份內的來源欄位是檔案自述，不是實體量測的證明。

接受版本 1 的回合 JSON（含單回合匯出），上限 256 KB、500 場。格式、來源、時間、分數或對戰統計有錯誤時整份拒絕，不部分寫入；不認得的額外欄位不保存。若確認前產生新回合，先重新預覽，再次確認才合併。取消或瀏覽器儲存失敗不改現有紀錄。

備份還原加入後，兩種視窗各 789 項瀏覽器回歸與 11 項整合測試通過。檔案讀取新增非同步路徑，瀏覽器測試給予 5 秒虛擬時間完成讀取，動作判定與計分門檻不變。此輪未重跑完整 Live。

## 自訂日期與紀錄取得方式

日期範圍選「自訂日期」，填入開始與結束日期。計算以台灣時間為準，包含起訖當日；日期未完整、無效或倒置時不提供 CSV 匯出。可與遊戲、輸入來源、對戰難度及紀錄取得方式篩選合併使用。

從此版起，透過備份新加入的回合由程式加上 `imported: true`，列表、摘要與 CSV 顯示「備份匯入」，並可單獨篩選。重複回合保留本機內容。標示會隨本機儲存保留；重新匯入時仍由這次匯入操作設定，不採信檔案宣稱的本機來源。較早版本匯入的資料無法自動追溯，歸在「本機／舊紀錄」。這些標示不證明真人或實體硬體來源。

最新針對兩種視窗各 795 項瀏覽器檢查與 11 項整合測試通過。瀏覽器測試已改用本機 Chrome DevTools 等待真實完成，取代前述虛擬時間預算，以避免非同步檔案讀取尚未完成就結束；動作與計分門檻仍不變。
